# 隧道收敛测缝台

测量员登记里程桩号，读数有两条路：交**弦长读数**由后台按“当量系数”换算成收敛毫米，或**直填收敛毫米**。两路算出同一个收敛数。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 弦长 → 收敛换算

- 换算关系：`收敛(mm) = 弦长(mm) × 当量系数`，默认系数 1.0。
- 弦长读数不能直接当毫米用：必须先换算成收敛再判合格。
- 当量参数在页眉「当量换算」专页维护：
  - 测量员可改系数（必须为正，范围 1e-6～1000），填错或越界会被退回并给出中文原因，旧值不动；
  - 巡检员能看当前系数与换算流水，但不能改系数、不能进单。
- 专页可只填弦长或直填毫米做「试算换算」，并展示换算流水。
- 每提交一条读数，进队记录与换算流水在**同一事务、同一拍落下**：要么一起可见，要么一起回滚。
- 判定只认换算后的收敛毫米：按当量应合格的弦长交进去判合格，故意交会超限的判超限。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| GET | `/api/equivalent` | 登录 | 读取当前当量系数 |
| PUT | `/api/equivalent` | 测量员 | 更新当量系数（越界/非法 400，原因在 `detail`） |
| POST | `/api/equivalent/preview` | 登录 | 试算：`chord_mm` 或 `delta_mm` 二选一 |
| GET | `/api/ledger` | 登录 | 换算流水（巡检员可看） |
| POST | `/api/logs` | 测量员 | 进单：`chord_mm` 或 `delta_mm` 二选一，记录与流水原子提交 |
| GET | `/api/logs` | 登录 | 收敛记录列表 |

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16（旧表自动轻量加列迁移）
