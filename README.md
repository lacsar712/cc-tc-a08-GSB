# 隧道收敛测缝台

测量员登记里程桩号与读数。弦长读数不能直接当毫米用：后台先按当量换算成收敛毫米
（`收敛 = (弦长 − 基准弦长) × 当量系数`），也可以直填毫米，两条路算出同一个数。
接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。
页面是 Svelte，页眉可进入「换算专页」：维护当量参数、录入弦长或毫米、查看换算流水。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

## 当量参数

- 单条参数（默认：当量系数 `0.5`，基准弦长 `0` mm），测量员可在换算专页修改。
- 合法范围：当量系数 `(0, 10]`，基准弦长 `0 ~ 100000 mm`；填错或越界退回 400 并说明原因。
- 换算结果与直填毫米统一保留 3 位小数；每条进队记录落一行换算流水（同事务），
  流水里快照当时所用当量，改当量不影响历史流水。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/login` | 登录 |
| GET | `/api/logs` | 测量记录列表（登录） |
| POST | `/api/logs` | 提交读数（测量员）：`chainage` + `chord_mm` 或 `delta_mm` 二选一 |
| GET | `/api/equivalent` | 读当量参数（登录） |
| PUT | `/api/equivalent` | 改当量参数（测量员），越界 400 带原因 |
| GET | `/api/conversions` | 换算流水列表（登录，巡检员可看） |
